description: Wake Gemini with the newest message from the Pi Reviewer (docs/inbox-gemini.md)
---

When the user types `/checkinbox`:

1. Read `docs/COMMS.md` (the protocol), then read the **newest entry** (bottom of the file) in `docs/inbox-gemini.md`.
2. Do what that entry says, following your part of the loop in `GEMINI.md`: read the referenced review file, apply the required changes, update your own report files, and when your phase is done run `docs\ping-pi.bat` from the project root.
3. Report to the developer in plain words: what you received, what you did, and what happens next.
