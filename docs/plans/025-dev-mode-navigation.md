# 025 — Dev Mode: start from your preset file, see the whole prompt

## Agreed with the developer

- Dev Mode opens on the **Universal .json** loaded in SillyTavern (read from
  the preset name, then the story preset's generation, then V11), marked
  "You're using this", with V11 / V10 cards to switch. The page explains it is
  the .json imported in SillyTavern, not the story preset of the Presets tab.
- Under it: **Preview full prompt**, **All add-ons**, "Show automatic parts",
  then three doors: **Chomusuke**, **Images (V2)**, **Presets** (story
  presets). The picked file's skeleton follows, every option at its place.
- The preview: the prompt this chat would send now, message by message as
  cards. Your edits pink, built-in editable texts green, story preset parts
  gold, automatic parts grey; hover names the piece, click opens its box.

## How

- `data/skeletonV10.js`: generated by `tests/tools/gen-skeleton.cjs` from the
  V10 Universal file in git history (`a3873d3^`); the tool writes both.
- `SLOT_IN_TAG` / `meguminSlotInTag(slot, json)` in `data/slots.js`: the tag
  each text slot sits in for each file (V11 rules in `[[block_rules]]`, lines
  in `[[this_turn]]`; V10 both in `[[blocks]]`). The file view nests them
  under that tag; the rest go to "Also in this file".
- Tracing: `setPromptTrace` / `traced` in `src/prompts/edits.js`; `editable`
  marks its text with private-use characters only during the preview's
  synchronous `buildBaseDict(true)`. `src/engine/promptPreview.js` (pure)
  fills a card like the injector and returns a tree of text / tag / edit
  nodes.
- An add-on page goes back where it was opened from (`session.back`).
